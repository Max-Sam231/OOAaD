## Этап 3. Правила из event storming (контекст «Игра»)

- [ ] Топливо: `IFuelable`, `CheckFuelCommand`, `BurnFuelCommand`, макрокоманда «движение с топливом»
- [ ] Запрет движения при пустом баке (событие «Движение невозможно»)
- [ ] Дозаправка: запрос топлива, проверка расстояния и наличия, пополнение
- [ ] Перемещение в точку: контроль достижения точки, остановка двигателей
- [ ] Выстрел: проверка наличия ракет → создание торпеды по правилам → движение; отказ, если ракет нет
- [ ] Коллизия: определить тип объекта → уничтожить объект или применить бонус
- [ ] Метеориты (объекты с постоянной скоростью)
- [ ] Условия завершения игры, событие «Матч завершён»

## Этап 4. Многопоточность

- [ ] ServerThread: потокобезопасная очередь + планировщик квантов между играми

- [ ] Игра ждёт, пока все агенты пришлют решения на текущий шаг
- [ ] Перемещение игры между потоками без взаимной блокировки (отдельная очередь / неблокирующая запись)
- [ ] Тесты на перемешанный порядок сообщений и на блокировки
- [ ] Нагрузочный тест endpoint: десятки тысяч сообщений в секунду локально
